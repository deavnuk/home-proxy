基本设置

决定哪些流量走代理。默认「智能分流」即可。

建立连接时同时尝试多个 IP，取最快的那个响应。网页通常部署在多个服务器上， 开启后打开速度明显更快。推荐开启。

允许用 IPv6 协议访问网站。国内 IPv6 普及度不一，开启后在部分网站可能出现 访问异常，且与分流机制配合不佳。除非你有 IPv6 需求，建议关闭。

开放本机代理端口，让手机、电视等设备可以手动设置代理地址来使用。 只用自动分流（网关模式）的话不需要开启，开启会增加安全风险。

日常用「info」即可。「debug」会记录每个连接细节，只在你排查问题需要看日志时才开， 否则日志文件会增长很快。
